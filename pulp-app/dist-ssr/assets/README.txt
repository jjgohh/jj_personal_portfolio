PULP — real assets required
===========================

Drop real files here. Missing files degrade to labelled placeholders rather than
breaking layout, so the site stays shippable while you source them.

REQUIRED (blocking)
-------------------
founder.jpg    4:5 portrait, min 640x800. The founder's note is the brand's
               stand-in for reviews pre-launch, so this is a conversion blocker,
               not a nice-to-have. A real photo of a real person only.

DELIBERATELY NOT USED
---------------------
No plantation, estate, mill or factory photography is referenced anywhere on the
site, and none should be added casually. On a provenance-led brand, imagery that
could be mistaken for documentation of a supply chain we have not photographed
would discredit the whole Traceability section. If you add provenance imagery it
must be REAL photography of the actual named facilities, captioned with where and
when it was taken. AI-generated or stock "plantation" imagery is not acceptable
here under any circumstances.

The Malaysia map in the Traceability section is an inline SVG, authored by hand
and explicitly labelled a schematic. It needs no asset file.
